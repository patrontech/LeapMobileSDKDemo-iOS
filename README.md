# Leap Mobile SDK Demo

This simple SwiftUI app demonstrates how to use the Leap Mobile SDK.

## Setup

Since the Leap Mobile SDK is in a private GitHub repo, the demo references it locally. In order to build, you'll need to check out the SDK itself in a directory _beside_ the SDK demo's directory.

```sh
mkdir demo
cd demo
git clone git@github.com:patrontech/LeapMobileSDK-iOS LeapMobileSDK
git clone git@github.com:patrontech/LeapMobileSDKDemo-iOS LeapMobileSDKDemo
```

The demo expects the SDK to live in a folder called `LeapMobileSDK`.

## Documentation 

The best documentation for developers is in the code itself, so that's where you'll find it: both in the SDK and in the demo. Be sure to read the `README` in the SDK as well.
